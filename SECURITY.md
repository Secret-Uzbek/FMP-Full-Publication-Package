# Security Policy

## Scope

This repository is publication-facing and package-facing.

Security concerns here include:

- leaked credentials or tokens;
- broken release or DOI workflows;
- damaged citation metadata;
- publication bundle tampering.

## Supported branch

- `main`

## Reporting

Do not publish exploit details or secrets in public issues.

Report privately to:

- `a.abdukarimov@fractal-metascience.org`

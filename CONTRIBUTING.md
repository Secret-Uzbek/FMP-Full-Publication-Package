# Contributing to FMP Full Publication Package

This repository is a publication package branch for peer-review-oriented FMP
materials and LaTeX sources.

Use it for:

- article and package cleanup;
- bibliography repair;
- citation and release coherence;
- detox of broken publication residues.

## Before contributing

Read:

- `README.md`
- `CITATION.cff`
- `SECURITY.md`
- `CODE_OF_CONDUCT.md`

And use `terra-legal` as the donor layer for repository rules and publication
governance.

## What belongs here

Good contributions include:

- LaTeX, bibliography, and metadata repair;
- article package cleanup;
- repository surface cleanup for public publication readiness;
- release and DOI pipeline alignment.

## What does not belong here

Do not use this repository as a generic archive for unrelated Terra files.

Avoid:

- dropping raw session debris into the root;
- keeping duplicate article packages without clear reason;
- inventing new parallel files where a stronger source already exists.

## Working sequence

1. Read the file and its publication neighbors.
2. Check if the same text already exists in a stronger article or package.
3. Repair encoding, citation, and structure first.
4. Keep publication metadata synchronized.

## Security

If you find a workflow, token, or publication-integrity problem, report it
through `SECURITY.md`.

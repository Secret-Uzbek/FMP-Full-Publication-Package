> Publication package layer of the Fractal Metascience Paradigm: article
> bundles, submission-ready materials, and outward-facing research packaging.

## Layer role

This repository is the explicit publication layer of the Terra / FMP weave.

It should hold:

- submission-ready publication bundles;
- article package files;
- outward-facing citation and dissemination material;
- release, archive, and DOI-facing publication surfaces.

It should not function as:

- a theory hub;
- a practice implementation repository;
- a false DOI placeholder surface;
- an undifferentiated residue dump.

## Reading path

1. `README.md`
2. `CITATION.cff`
3. article and package files in the root
4. release and DOI workflows in `.github/workflows/`
5. donor rules in `terra-legal`

## Ecosystem position

- `FMP-CENTRAL-REPO` — central public hub
- `Theory-of-fractal-metascience-paradigm` — theory layer
- `FMP-monograph` — monograph layer
- `AIUZ-terra-codex-FMP` — FMP package and standards layer
- `terra-legal` — donor governance and publication rules

## Layer boundaries

Keep here:

- publication-ready bundles;
- article-level package files;
- citation-facing and dissemination-facing artifacts;
- release automation for publication packages.

Do not overload this repository with:

- donor governance duplication;
- unrelated practice prototypes;
- archive dumps without publication role;
- fake pending DOI badges.
